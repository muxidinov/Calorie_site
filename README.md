🍎 Calorie Site
A modern web-based calorie and nutrition platform designed to help users track their daily nutrition and maintain healthier eating habits.
🌐 Overview
Calorie Site is the web interface of the Calorie platform. It provides users with a simple and convenient way to explore calorie-related information and interact with the nutrition system.
The platform is designed to work together with the Calorie Telegram Bot, creating a connected experience between the website and Telegram.
✨ Features
• 🍎 Calorie and nutrition tracking
• 📊 Nutrition-focused user experience
• 🥗 Food and meal information
• 📱 Responsive design
• ⚡ Modern web interface
• 🔗 Integration with the Calorie Telegram Bot
• 🎯 Simple and user-friendly navigation

🚀 Getting Started
Clone the repository:
git clone https://github.com/muxidinov/Calorie_site.git
Open the project:
cd Calorie_site
Install dependencies if required:
npm install
Start the development server:
npm run dev

If the project uses environment variables, create a .env file locally.
Never commit .env files or API keys to GitHub.
